## 🛠️ Tech Stack Used

- **Frontend:**  React
- **Styling:** Tailwind CSS 
- **Backend :** Node.js / API routes ( contact me page )
- **Other Tools:** Git, GitHub

---

## Installation

- Clone the repository:

```bash
git clone https://github.com/Pankeet/Pankeet-Manubarwala
cd frontend
```

- Install dependencies:

```bash
npm install
```

---

## Run Locally

```bash
npm run dev
```

Open in browser:
```
http://localhost:5173
```
